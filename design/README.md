# 🖌️ 设计系统

设计类 skill，涵盖 UI/UX 设计、配色方案、字体搭配、动效、布局模式。

## Skill 清单

### `ui-ux-pro-max`

UI/UX 设计智能百科：67 种设计风格、96 套调色板、57 种字体搭配、25 种图表、13 个技术栈（React、Vue、Svelte、Flutter 等）。

> **场景示例：** 用户说“帮我用 glassmorphism 风格做一个 SaaS 数据面板” → 自动匹配合适的玻璃态配色、字体搭配和 shadcn/ui 组件，产出一套完整的设计方案。

### `theme-factory`

主题工厂：10 套预设主题（极地霜冻、午夜银河、日落大道等），每套含完整配色 + 字体搭配，可一键套用或自定义生成。

> **场景示例：** 用户说“帮我的 PPT/落地页换一套科技感主题” → 展示 `theme-showcase.pdf` 供选择，选定“Tech Innovation”后一键替换所有颜色和字体。

### `canvas-design`

Canvas 设计哲学：创建海报、艺术作品、PNG/PDF 静态视觉。内置 30+ 开源字体，强调原创设计，避免模板化风格。

> **场景示例：** 用户说“帮我设计一张技术大会海报” → 根据大会主题选择字体和配色，用 Canvas 绘制独特的海报视觉，输出高质量 PNG。

### `accessibility-testing`

WCAG 2.1 AA/AAA 可访问性审计：检测网页可访问性违规，产出可操作的修复方案和代码。

> **场景示例：** 新做了一个登录页面 → 审计对比度、键盘导航、屏幕阅读器支持，发现登录按钮颜色对比度不足，输出具体的 CSS 修复代码。

### `wireframing`

文本线框图设计：支持低/中/高保真度，包含组件清单、交互标注和响应式断点规划。

> **场景示例：** 用户说“我想做一个电商首页，帮我先画个线框图” → 输出带页面结构、组件布局、交互流向的文本线框图，确定方案后再开始写代码。
